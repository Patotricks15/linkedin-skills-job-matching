\begin{abstract}
We evaluate a classical, fully non-neural two-stage retrieve-then-rank
pipeline -- BM25 lexical retrieval followed by LambdaMART (LightGBM
\texttt{lambdarank}) re-ranking over handcrafted features -- for matching
candidate skill profiles to job postings. The system includes
point-in-time-safe features, a documented self-supervised proxy for the
missing candidate-job interaction signal, taxonomy-normalized skill
overlap, strong non-neural baselines, reproducible Floci/AWS
infrastructure, and offline-to-online serving parity tests.
\end{abstract}
